# CamaroDiag Gen5 (2010–2015 Chevrolet Camaro Android App)

Native Kotlin + Jetpack Compose OBD-II & GM Enhanced CAN/UDS diagnostic application for 5th-generation Chevrolet Camaro (V6 LLT/LFX & V8 LS3/L99/LSA/LS7, US & EU/ECE).

## Build APK via GitHub Actions (No Local Android Studio Required)
1. Upload this repository to GitHub (preserving the `.github/workflows/build-apk.yml` file).
2. Open the **Actions** tab on GitHub and run **Build CamaroDiagGen5 Android APK**.
3. Download the compiled `app-debug.apk` from the **Artifacts** section and install it on your Android device.
